# TheInk — Developer Writing & Reading Community

A premium, highly interactive blogging platform built for developers to read, write, and share deep dives, opinions, and tutorials.

![Screenshot](https://img.shields.io/badge/Vite-React-646CFF?logo=vite&logoColor=white)

## Features

- **Rich Aesthetics**: Sophisticated cream/sepia/ink color palette with custom typography (Playfair Display & Lato) and fluid transitions.
- **Dynamic Interactions**: Hover effects, responsive layout, modal confirmations, and smooth UI animations.
- **Markdown-Lite Content**: Write posts using basic markdown elements like bold text (`**text**`), inline code (\``code`\`), and code blocks (\`\`\`lang ... \`\`\`).
- **Interactive Feed**: Explore trending posts, filter by tags, search titles and excerpts instantly.
- **Comments & Engagement**: Like posts, toggle comment likes, add new comments, and delete owned content.
- **Mock Authentication**: Quick switch or registration to write, like, edit, and comment.

## Tech Stack

- **Core**: React 18, JSX
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (modular design tokens and utility variables)
- **Fonts**: Google Fonts (Lato, Playfair Display)

## Getting Started

Follow these steps to run the application locally:

### 1. Install Dependencies

In the root of the project, run:

```bash
npm install
```

### 2. Start Development Server

To run the application in development mode:

```bash
npm run dev
```

The application will start, and the address will be displayed in the terminal (usually `http://localhost:5173`). Open this link in your browser to view the application.

### 3. Build for Production

To create a production build in the `dist` directory:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
